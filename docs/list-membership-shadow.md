# 每日榜單測試比較

正式日報完成後，`list-comparison` 讀取同日正式榜單及已保存的行情和財務快照，產生獨立的「測試中策略」LINE 報告。報告列出測試入榜、留榜、落榜和同日正式榜單。連續兩次觀察之後，報告並列兩張前日榜單在當日開盤至收盤的上漲檔數與價格覆蓋。測試資料和 LINE 重試金鑰保存在 `screener-tests:test-runs/list-membership-v1`。

策略 ID 為 `test-growth-flow-top20-keep40-breadth40-55-v1`。研究的流動性池沿用連續121筆有效行情、20日成交額代理中位數3千萬元、原六檔排除，以及趨勢／成長／資金／防禦15／35／35／15%計分。排名使用全池。榜單在前40名內保留既有成員，再按分數補至20檔。廣度以合格池中高於60日均線的比例計算，低於40%關閉，至少55%開啟。測試開始從空榜與關閉狀態起算。缺少前一交易日的測試觀察時，報告標記重新建榜。

正式觀察採實際當日可得的營收與 EPS 季別。測試用公開資訊觀測站季度 XBRL ZIP 取得同份財報的去年同期 EPS。只採與當日快照累計 EPS 一致的值。報告揭露可用覆蓋，逐日快照記錄來源摘要及雜湊。歷史回測採研究公告時點假設，兩者的每日名單可有差異。

排程沿用既有 `LINE_ENABLED` 與配額檢查。手動觸發 `daily` 可用 `send_line=false` 產生當日預覽。完成送達以測試目錄當日 `data/delivery` 的 `SENT` 為準。已送達的正式報告仍由原防重送機制管理。隔日才完成的資料及事後補跑不建立當日測試觀察。
