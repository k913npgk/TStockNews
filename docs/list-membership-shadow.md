# 每日品質＋動能測試比較

正式v8日報完成後，`list-comparison` 產生獨立的品質＋動能測試榜單。正式v8規則不變；舊成長＋資金與前40留任版本保留原資料。新版本`test-quality-momentum-top20-v1`，所有快照、會計快取與LINE收據僅存於`screener-tests:test-runs/quality-momentum-v1`，不合併正式資料或績效。

每天重排Top20，ROE品質與中期價格動能各占一半。品質為TTM歸屬母公司淨利／期末歸屬母公司權益；個別報表採淨利／權益。TTM使用當年累計＋前一年全年−同份報表去年同期，Q4直接全年；EPS與口徑需已知。這是研究品質代理，非完整MSCI品質指數。沒有原前40留任、40/55廣度空榜或六檔事後排除。

價格動能跳過最近21交易日，比較126及252日，除以最近126日報酬年化波動後取百分位合成；252日不足時只用126日。至少148日連續行情、近20日收盤乘成交股數中位數至少3千萬元。只使用正式已保存行情，最多274日。切換時雲端僅173日，故只使用6個月訊號，與本地有完整12個月歷史時的名單可能不同；快照保留可用12個月動能的公司數。未上傳本地FinMind原始行情。

為延續已比較的共同資料池，另要求TTM EPS及營收模型所需4個月同比資料完整；未知不填0。季財報採季末+60日、年報採年末+120日的固定可用日，月營收採次月15日。可能不納入提早公布的季報／營收。來源為同日正式財務快照的月比較值與官方XBRL ZIP會計資料，保留來源URL、SHA256、首次觀測日期。會計快取較晚觀測不得用作早日的live觀察。

報告列出排名、股票及較上次排名變動，保留落榜與前一交易日測試榜單方向比較。變動依連續前一交易日同版前瞻名單的位置計算：↑／↓幾名、持平、新增；首次、觀察中斷、版本不同或事後補發資料不能比較時顯示「—」，落榜亦顯示「—」。不列正式v8比較、入榜／留榜標籤、個股漲跌幅、首次建榜說明、會計期別、營收模型月份、完整資料池及原頁尾說明；相關資料仍保存在快照。新版本使用新root並拒絕舊version延續。前一天榜單的方向比較使用本日收盤價對前日收盤價，缺價明示未知；不只計新入榜。同股重複訊號與重疊期限不是獨立樣本。

每日測試報告另列1／3／5／10／20交易日績效：平均與中位數價格報酬、上漲比例、有效／全部筆數、待追蹤及資料待確認筆數。自入選後下一交易日開盤至第N個交易日收盤計算，不扣費用、不計股息；同股重複入選按每日訊號逐筆統計，非投資組合報酬。僅統計同版且明示非retrospective的隔離前瞻快照；舊策略、事後補發、未來日期不納入。未到期與缺價不填0、不納入報酬或上漲比例分母。共用數值追蹤函式，正式績效排除測試資料的規則維持不變。結果及來源雜湊僅存於`test-runs/quality-momentum-v1/performance/<日期>.json`，隨`screener-tests`保存；已保存的當日統計、報告與重試收據仍不可改寫。
